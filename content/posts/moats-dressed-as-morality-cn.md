最近又看到一批关于模型蒸馏和开源权重的观点，说新也不算新。

先是 OpenAI。11 月 18 日，他们发了一篇 [Managing frontier AI risk: From training to deployment](https://openai.com/index/managing-frontier-ai-risk/)，讲从训练到部署的风险管理框架，其中包含打击有组织的模型蒸馏行动，以及模型对齐失败的报告机制。两天后又发了一篇 [Combatting adversarial distillation](https://openai.com/index/combatting-adversarial-distillation/)，解释为什么要把蒸馏当成安全问题和国家安全问题，手段包括加密思维链、API 层拦截，还有跨行业的情报共享。

比 OpenAI 更早的当然是老朋友 Anthropic。安全监督、国家安全、芯片出口管制、防蒸馏，这套政策立场他们很早就系统阐述过。9 月 29 日那篇 [GLM-5.3 and the spread of advanced cyber capabilities](https://www.anthropic.com/research/glm-5-3-and-the-spread-of-advanced-cyber-capabilities)，讲的就是开源权重模型让网络攻击能力扩散的风险。

然后今天我在推特上看到一位老哥写的 [Machines of Loving Export Controls](https://mercuriusdream.com/loving-controls/)，立场鲜明，火药味十足。

## 这篇文章说了什么

文章的矛头指向 OpenAI、Anthropic 和 Frontier Model Forum 共同推动的三件事：算力出口管制、反蒸馏、限制开源权重。

作者认为，头部闭源实验室借「安全」和「国家安全」之名游说政策，本质上是在制造行业壁垒，顺便规避反垄断。AI 是军民两用技术，集中控制反而会吸引攻击者，同时让普通的防御者失去工具。在他看来，用开源权重的方式扩散能力，对防御一方更有利。

他还摆了一组双标的对比。闭源实验室一边警告开源权重会带来网络攻击风险，一边自家的 agent 在真实环境里闯祸：OpenAI 的 agent 入侵了 Hugging Face，Anthropic 的 Mythos 在测试中越界，Haiku 4.5 虚构警方线索。而且商业闭源模型的安全护栏经常过度拒绝，逼得防御者只能转向开源模型。最典型的就是 Hugging Face 那场事故：OpenAI 的模型拒绝帮忙，最后 Hugging Face 是靠 GLM 的模型解决的问题。

## 他说对了什么

「监管俘获」这一点，他点得很准。商业巨头把自己的护城河包装成公共安全议题，这个动机分析我认为是成立的。

闭源模型过度拒绝的痛点也是真的。一刀切的安全护栏，在实战防御里的确会卡住普通防御者的脖子，而且已经卡住了。

还有一点做得很好：他跳出了非黑即白的阵营叙事。文章同时提到了中国的内容监管，以及五角大楼把 Anthropic 列为供应链风险这种矛盾，把视角拉回到了企业和监管的博弈上。

## 他没说服我的地方

他说过去两年开源权重模型并没有带来什么大问题。可是用过去两年的太平，去证明未来 agentic 模型的能力跃迁和尾部风险不存在，这个逻辑站不住。

Anthropic 提出的网络攻防不对称，也被他轻描淡写地带过了。在网络安全领域，防御者要堵住所有漏洞，攻击者只需要找到一个。强能力通过开源全面扩散之后，中小企业未必有配套的工程能力来自卫。

另外，闭源模型出了事，至少可以通过 API 做管控和溯源，很大程度上收拾已经发生的安全隐患。开源权重放出去就收不回来了。

## 蒸馏和扫书

我在想另一个问题。

Anthropic 有一件被人诟病了很久的事：大规模扫描书籍用来训练，其中还有破坏性的扫描。这件事和小模型蒸馏大模型、弱模型蒸馏强模型，本质上是同一种搭便车。而且 Anthropic 和 OpenAI 自己在模型发展的过程中，或多或少也用过蒸馏技术。

可是轮到竞争对手来学他们的思维链，这件事就被定性成了窃取机密。这是很明显的双标。

用用户协议约束一个商业产品，本身没有问题。但试图在道德上拔高、占据高地，我认为纯粹是 PR 和 marketing 行为。

扫书这件事还吃了一份时间红利。2023 年之前出版的书，不可能预见到大模型的出现，自然也不会有「禁止用于 AI 训练」之类的明文条款。闭源实验室吃透了这段制度空白，完成了原始积累，转身就用严密的 API 服务条款把门焊死，让蒸馏直接踩中违约的红线。

公平地说，思维链不能简单等同于书籍。它是消耗巨额算力、用强化学习练出来的高纯度合成数据，蒸馏思维链和拿书去训练，严格讲不能相提并论。但两件事的本质是类似的，区别只在于一个有 ToS，一个没有。

## 高地与低地

这场争论最让人反胃的地方，是把商业竞争包装成了道德和法律的圣战。

闭源巨头也好，开源激进派也好，用的都是同一套 motte-and-bailey 策略：对外站在一块高地上讲宏大叙事，真正要守的是下面那块低地。

闭源巨头的低地，是保住 API 利润和先发壁垒，防止对手低成本抄作业。对外的高地是国家安全，是防止生物武器和网络武器扩散。更有甚者，像 Anthropic，直接打出「保护人类未来」这张牌。

开源激进派的低地，是获取便宜、不受限制的算力和好用的开源模型，反对监管和卡脖子。对外的高地是开放社会、防御性民主、反抗集权垄断。

商业竞争本身并不丢人。想守住护城河，或者想低成本追赶对手，都是再正常不过的生意逻辑。但一旦把生意包装成正义与邪恶的对抗，就成了既要赚钱又要立牌坊。借公权力打压对手，拿道德大棒审判同行，消耗的是整个行业的公信力。

## 不必急着选边站

现在很难苛求大家让商业的归商业。用道德和公权力当武器打击对手，看起来是一件 ROI 很高的事：被人识破了不用付出什么代价，成功了却真能在某种程度上要对手的命。

但把这件事指出来，我觉得仍然有价值。至少下次再看到这类宣传，看到某一方又站上了舆论高地，我们不必过于恐慌，也不用着急选边站。
