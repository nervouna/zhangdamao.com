# Ignore the Blueprint

Personal website of GUAN Xiaoyu (a.k.a. ZHANG Damao).

This site is:

* Built with [Pelican][0]
* Managed with [mise][1] and [uv][2]
* Deployed on [CloudFlare][3]

The content is 100% hand written. Some of the metadata is [generated by GPT][4].

## Setup

Set up the local environment with `mise` and `uv`:

```bash
mise install
mise current
uv sync --locked
ollama pull qwen3.5:0.8b
```

Make sure Ollama is installed separately and that the model you want to use is already pulled locally.

`httpx[socks]` stays enabled intentionally because this shell auto-sets `all_proxy=socks5://127.0.0.1:7890`, which local Ollama/httpx usage can rely on.

The repo pins Python in `mise.toml` and dependencies in `pyproject.toml` + `uv.lock`.

Use `uv run` for project scripts:

```bash
uv run python create_post.py --help
uv run python generate_post_header.py --help
```

## Common Commands

Build the site:

```bash
make html
```

Cloudflare Pages uses the tracked production entry point:

```bash
bash scripts/build-pages.sh
```

The Pages dashboard must select Python 3.11.15, set
`SKIP_DEPENDENCY_INSTALL=1`, and use `output` as the build output directory.
The script pins uv, performs a locked sync, and builds with `publishconf.py`.

Serve the site locally with auto reload:

```bash
make devserver PORT=8000
```

## Generate post headers

Post headers are generated locally with Ollama.

Run `uv run python generate_post_header.py` to scan untracked markdown files under `content/posts/`.

Run `uv run python generate_post_header.py content/posts/my-post.md` to process specific files.

Run `uv run python generate_post_header.py --model llama3.2 content/posts/my-post.md` to override the default model.

Run `uv run python generate_post_header.py --think content/posts/my-post.md` to enable model thinking output. Thinking is disabled by default.

Run `uv run python generate_post_header.py --timeout 30 content/posts/my-post.md` to fail faster when the local Ollama request stalls. Use `--timeout 0` to wait indefinitely.
